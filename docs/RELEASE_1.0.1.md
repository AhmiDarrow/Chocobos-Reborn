# Chocobos Reborn 1.0.1 - Whiskerwind

Polish and fixes on the 1.0.0 Whiskerwind drop. Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server. Existing worlds rebuild Whiskerwind once (village v12) and relay course islands (course v5).

- **Start arrows**: every course now paints a real block arrow on the grid past the stalls (3-wide shaft, 45-degree head, gold tip), not a diamond smear.
- **Courses**: chequered start line, six stall boxes, higher gantry, marshal board, rumble strips, lamps on both verges, yellow boost-lane dashes, warning posts before water/lava/ridge/mud, themed void rims.
- **Whiskerwind**: practice sprint and long gates, Sage Wynn's gysahl bed, sandstone rim, lantern posts, waterfall lips; town music is a day/night playlist that no longer layers over vanilla.
- **The field**: named FF racers (Priscilla, Jessie, Wedge, Biggs, Selphie and the rest of the sixteen), with guests from the class above; every racer rolls ±5% form each heat.
- **Heats**: the island is built when you pick the course, not at GO; AI jockeys mount after the birds exist; you can enter a class at or below your bird's (lower classes pay half and do not promote).
- **Training**: one green every five minutes.
- **Almanac, gates and pocketwatch**: sharper item and portal pixels; almanac layout pass.
- **Breeding**: End and Nether birds breed true.
