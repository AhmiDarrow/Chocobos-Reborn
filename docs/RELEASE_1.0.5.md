# Chocobos Reborn 1.0.5 - Follow, Stay, Wander

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server. Existing saves, farms and courses are untouched; tame birds load on Follow, or on Stay if they were sitting.

- **Orders for tame birds.** The equipment screen (sneak and right-click an owned adult with an empty hand) has Follow, Stay and Wander tabs. Each order gets its own kweh.
- **Wander.** The bird stops following and roams within 24 blocks of where you gave the order. Lead it or ride it somewhere new and it wanders there instead.
- **Right-click** still sits a bird down or stands it up, and a bird stood back up goes back to what it was doing: following or wandering.
- **Trips to Whiskerwind** only bring birds set to Follow; wandering and staying birds stay home.
