# Chocobos Reborn 1.1.3 - Class Rivals

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Install this jar on the server and on every rider.**

**Ahmi and Risika on Class C**

- Class C ranked heats seat Ahmi and Risika in the named stalls. Risika
  rides a touch ahead of Ahmi, the same hard-but-beatable gap Teiyo and
  Jolo keep from Class B up. From Class B onward the named pair is Teiyo
  and Jolo again.
- Their birds race as Yellows with Flame and Purple look plumage. The
  jockeys wear player skins on the course, and Rook, the board, and the
  almanac name them.

**A longer climb per class**

- Promotion is still points by heat length, but each class has its own
  bar: Class C 36, Class B 54, Class A 72. Class S never drops and shows
  the Class A bar. Older birds on the uniform-36 ladder scale onto the
  new bars when the world loads.
- The course picker, gossip, lounge signs, Race Hall board, and almanac
  all say C36 / B54 / A72.
