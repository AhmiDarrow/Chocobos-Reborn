# Chocobos Reborn 1.1.11 - Whistle Calls

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**The whistle has a voice**

- The Chocobo Whistle now sounds every time you blow it, not only when a bird answers.
- It has four different calls and plays them in turn, so two blows in a row never sound the same.
- If no bird hears it, the whistle rests for a second before you can blow it again, so holding the button no longer spams it. When birds answer, the usual three-second wait still applies.
- Subtitles show "Chocobo Whistle blows".

The calls are original recordings made for this mod.
