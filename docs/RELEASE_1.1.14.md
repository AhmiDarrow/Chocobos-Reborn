# Chocobos Reborn 1.1.14 - Said Once

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Fixes**

- **Hints print once.** With Tribal Power, Ninjacat Skies Core or Shamanic Mounts installed, every hint line showed once per mod, four times over. Each mod now speaks only for its own items.
- **Queue clock.** The heat queue countdown uses plain digits in every language.
- **Quieter rejoins.** Joining a server after a logout no longer logs a spurious "race frames stalled" line, and a singleplayer world's race data is released when the world closes instead of staying in memory for the session.
