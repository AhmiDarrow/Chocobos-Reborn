# Chocobos Reborn 1.2.0 - Your Language

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

Install this jar on the server and on every rider. Network formats are unchanged, so a 1.1.15 client can still join. The languages below are in this jar.

**Languages**

- Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Follows your Minecraft language setting.
- Mexican Spanish uses the same Spanish text. English is the fallback when a line is missing.
- Wide labels shrink to fit. The vanilla font draws Japanese, Korean and Chinese.
