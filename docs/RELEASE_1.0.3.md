# Chocobos Reborn 1.0.3 - Gysahl

Balance pass on 1.0.2. Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server. No world changes: existing saves, farms and courses are untouched.

- **Gysahl is the only green found in the wild.** A grown gysahl plant drops greens and seeds only; it no longer throws a Krakka, Tantal or Pepio Nut.
- **No nut drops from mobs.** Ravagers no longer drop Carob Nuts and piglin brutes no longer drop Zeio Nuts. Bilo the Nutkeeper in Whiskerwind sells all eight nuts, and races from Class A up pay out Carob, with a rare Zeio at Class S. Colour breeding runs through the town, as in FF7.
- **Farm Stablehand** sells Gysahl Greens and seeds only. Krakka and the plain nuts are Whiskerwind stock.
- **Krakka and Tantal** can still be crafted from Gysahl (bone meal or sugar) as the cheap early step.
- Almanac, README and store page updated to match.
