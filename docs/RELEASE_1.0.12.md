# Chocobos Reborn 1.0.12 - Sound sleepers

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Fixes**

- **Whiskerwind's beds no longer explode.** Nobody sleeps or sets a respawn point in
  Whiskerwind, and the game used to answer a click on one of the village's beds the
  way the Nether does: with an explosion. The beds are furniture now. A click does
  nothing but tell you so. Respawn anchors there are left alone the same way.
