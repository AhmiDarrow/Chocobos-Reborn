# Chocobos Reborn 1.1.12 - Only Followers

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**The whistle calls the birds following you**

- The Chocobo Whistle now calls only the chocobos you have set to Follow. Birds left on Stay or Wander stay where you put them, instead of the whole flock arriving at once.
- If none of your birds is following you, the whistle says so: set one to Follow to call it.
- A parked bird in a far-off chunk is skipped without loading that chunk. A bird saved before this version is checked once, the next time its chunk loads.
