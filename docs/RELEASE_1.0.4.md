# Chocobos Reborn 1.0.4 - Wild Gysahl

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server. Existing saves, farms and courses are untouched.

- **Wild Gysahl.** A new plant, Gysahl growing wild. Pick it for 1-2 Gysahl Greens and up to 2 seeds (Fortune helps with seeds). It does not grow or spread, so plant the seeds to farm it.
- **For other mods' worlds.** Wild Gysahl stands on any block tagged as dirt, and ships ready-made patches (`chocobosreborn:wild_gysahl_thicket`, `chocobosreborn:wild_gysahl_scatter`) that any mod or datapack can place in its biomes. Tribal Power 3.5.0 uses them to grow Gysahl in The March.
- **Fix:** Chocobos Reborn no longer crashes a development environment (another mod's workspace or a pack-dev run) looking for its test suite, which the published jar leaves out. Players were never affected.
