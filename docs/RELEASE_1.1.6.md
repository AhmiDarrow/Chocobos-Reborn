# Chocobos Reborn 1.1.6 - The Whistle

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Install this jar on the server and on every rider.**

**Chocobo Whistle**

- Craft it from gold nuggets and a feather. One feather on top, a nugget on each side, and one nugget below.
- Use it and your own tame chocobos come to you from any distance, including another dimension. Stay and Wander are included. Up to eight come. If you own more than that, the rest stay where they are and the message says eight came.
- A bird in a heat stays. A bird you are riding stays, and you are not put back in the saddle. A bird on a lead, a bird someone else is riding, and a bird already within sixteen blocks stay put.
- A bird the whistle has never been near may need you to see it once, so the whistle knows where it is.
