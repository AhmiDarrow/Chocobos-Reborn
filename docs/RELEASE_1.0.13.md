# Chocobos Reborn 1.0.13 - Clear pages

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Fixes**

- **The almanac's birds are sharp again.** Since 1.0.10 the eight breeds in the
  almanac were drawn with the coarse far-away model, so they looked crumpled and
  blocky. The book's birds are always drawn at full detail now. Birds in the world
  still draw lighter at a distance, as before.
