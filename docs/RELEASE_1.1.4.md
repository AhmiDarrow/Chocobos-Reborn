# Chocobos Reborn 1.1.4 - Earned in Class

Minecraft 1.21.1, NeoForge 21.1.249, Java 21, client and server.

**Install this jar on the server and on every rider.**

**The farm line is earned in the right class**

- Colour breeding now counts only first places a bird won in that
  stage's own class. A win counts for the class the bird is in when it
  wins; the win that promotes it counts for the class it leaves.
  Unranked, below-class and duel wins never count.
- Green or Blue: two Good Yellows and a Carob, each parent with 5
  Class C wins. Certain at 16 combined.
- Black (White on a miss): a Great Green and a Great Blue and a Carob,
  each parent with 8 Class B wins. Certain at 24 combined.
- Gold: a Wonderful Yellow and a Wonderful Black and a Zeio, each
  parent with 10 Class A wins. Certain at 32 combined.
- Once both parents qualify, the chance starts at 25% and climbs
  evenly to certain.

**Birds you already have**

- A bird saved before this update has its lifetime wins shared out
  once across the classes it has reached, lowest class first (up to 9
  in C, 14 in B and 18 in A), with the rest in its current class. The
  almanac's records are converted the same way.

**Where it shows**

- The almanac adds a "First places by class" line to each bird, and its
  breeding hints show the wins needed, the bird's wins and the combined
  wins for certainty in the stage's class. The Carob and Zeio messages,
  nut tooltips and villager gossip say the same.
